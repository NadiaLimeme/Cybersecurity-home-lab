# Cybersecurity Home Lab

## Purpose

This home lab is a safe environment for learning cybersecurity and performing authorised security testing.

## Lab Machines

### Kali Linux

Kali Linux is used as the security workstation.

It is used for security tools, network testing and analysis.

### Metasploitable 2

Metasploitable 2 is the intentionally vulnerable practice target.

It is used only for authorised testing inside this lab.

## Main Tools

- Kali Linux
- Oracle VirtualBox
- Python
- Git
- GitHub
- Nmap
- Wireshark
- Burp Suite

## Network

The Kali Linux and Metasploitable 2 virtual machines communicate through a Host-only VirtualBox network.

This keeps the practice environment separated from the normal network.

## Safety

All security testing in this lab is performed only against the authorised practice target.
